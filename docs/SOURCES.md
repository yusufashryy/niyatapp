# Where Niyat's religious content comes from

Religious accuracy comes first. Nothing Qur'anic, no hadith wording and no prayer time in Niyat is generated by AI. Every item below comes from a named, verifiable source, and the Qur'an files are checked byte-for-byte against published SHA-256 checksums, both in the tests and inside the app (More › About).

All five were obtained through [risan/quran-json](https://github.com/risan/quran-json), which only republishes sources whose licence allows it and records a checksum for each file. The full hashes are in `Niyat/Features/Quran/QuranEdition.swift`.

- **Hafs texts** include the Bismillah at the start of verse 1. Niyat shows it as a header, as in the mushaf (see `QuranStore.removingBismillah`), without changing the file.
- **Warsh and Qalun** use the Madinan count. Each verse carries the Hafs verse number(s) it covers, which is how translations and bookmarks line up. The Qur'anpedia licence asks redistributors to keep their copy current. Check for newer dump versions before each release.
- **Not included:** IndoPak and other scripts. The widely used versions are restricted. A licensed IndoPak text (DigitalKhatt, MIT) exists but numbers Al-Fatiha differently and needs another font, so it's a candidate for later.

## Recitation audio (streamed)

Options considered:

| Source | Per-verse files | Licence / terms | Rate limits and pricing | Offline | Verdict |
|---|---|---|---|---|---|
| **Islamic Network CDN** (cdn.islamic.network, used by api.alquran.cloud) | Yes, Hafs, ~20 reciters, numbered 1–6236 | Free for non-commercial use; reciter copyright retained | Free; no published per-user limit (plain CDN files) | Can be cached | **Chosen.** Clear terms for a free app, verse-level files, stable URL scheme |
| EveryAyah.com | Yes, many reciters | No licence published | Free, unspecified | Can be cached | Not used: terms unclear |
| MP3Quran (mp3quran.net) | No, whole surahs only (includes Warsh reciters) | Redistribution allowed with attribution | Free | Can be cached | Possible later for whole-surah Warsh/Qalun listening; can't sync per verse |
| Quran.com / Quran Foundation API | Yes | API terms and client credentials; content for personal non-commercial use | Rate limited; account needed | Limited | Not used: account and terms overhead |

Notes on the chosen source:
- **Riwayah:** it's Hafs only, so recitation is switched off for Warsh and Qalun rather than playing mismatched audio.
- **Bismillah:** before verse 1 of a surah (except 1 and 9), the player plays verse 1:1 (the Bismillah) first.
- **Missing files:** Husary, Minshawi and Basfar's collections are missing one verse file each on the CDN. The player skips a missing verse rather than stopping.
- **Caching:** audio currently streams. A future "download surah for offline" option could cache files locally; the licence allows it for non-commercial use.

## Hadith

- **Recitation reward estimate:** Jami' at-Tirmidhi 2910 (Abdullah ibn Mas'ud), shown as an English paraphrase and linked to [sunnah.com/tirmidhi:2910](https://sunnah.com/tirmidhi:2910) rather than quoting Arabic wording in the app.
- **"Actions are judged by intentions":** the opening words of the famous hadith (Bukhari 1, Muslim 1907) in the More tab.

## Prayer times

Calculated on-device with [Adhan](https://github.com/batoulapps/adhan-swift) (MIT), using the standard published parameters for each method (Muslim World League, ISNA, Umm al-Qura, Egyptian, Karachi, Moonsighting Committee, Dubai, Kuwait, Qatar, Singapore, Tehran, Diyanet). Tests cover ordering, Hanafi Asr, adjustments, high latitudes and midnight crossover.

## Qibla

Great-circle initial bearing to the Kaaba (21.4225° N, 39.8262° E). The app's value (Adhan) is tested against an independent implementation for 20 cities and a global grid, and against published values.

## Hijri date

Apple's Umm al-Qura calendar (`Calendar(identifier: .islamicUmmAlQura)`), with a ±2-day adjustment for local moon sighting. Arabic month names come from the system, not from hand-typed text.
